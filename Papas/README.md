# Pedidos Papas

Sistema en desarrollo para gestionar pedidos de papas fritas. El proyecto
busca facilitar el registro de pedidos, el seguimiento de su estado y el
mantenimiento de un historial de ventas.

## Características

- Registrar pedidos de papas fritas y sus detalles.
- Actualizar el estado de cada pedido (pendiente, en preparación, entregado).
- Llevar un historial de ventas para análisis posteriores.

## Uso

Por ahora el proyecto se encuentra en etapas iniciales, por lo que la
aplicación aún no está disponible. En futuras versiones se incluirán las
instrucciones necesarias para ejecutar el sistema y colaborar con su
desarrollo.
